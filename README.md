# Chrome Policy Merge

Chrome Policy Merge 4.0.0 is a production-ready command-line tool and Python library for
deterministically merging Chrome enterprise policy JSON files from a directory into one
validated output file, then archiving the source files into a timestamped backup snapshot.

## Overview

Chrome enterprise policy rollouts often accumulate multiple JSON fragments generated by
different teams, deployment systems, or staging steps. This tool solves the operational
problem of combining those fragments safely:

- Only intended JSON policy files are processed.
- Files are merged in deterministic natural filename order.
- Invalid JSON or non-object JSON is rejected before anything is moved.
- Output is written atomically.
- Source files are archived into unique backup snapshots instead of being overwritten.
- Optional restore support copies a snapshot back into the input directory.

## Installation

Create and activate a virtual environment, then install from the repository root:

On Windows:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install .
```

On Linux or macOS:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install .
```

For development tooling:

```bash
python -m pip install -e ".[dev]"
```

The console entry point is installed as `chrome-policy-merge`. Module invocation with
`python -m chrome_policy_merge` is equivalent and can be useful in constrained environments.
Source installs, development installs, and build workflows are supported on standard CPython
3.10+ runtimes. Some embedded vendor Python distributions on Windows do not support source
installs, editable installs, or isolated build hooks reliably. In those environments, build
the wheel first and install from `dist/`.

Wheel-based installation:

```bash
python -m build
python -m pip install dist/chrome_policy_merge-4.0.0-py3-none-any.whl
```

## Quick Start

Merge all JSON policy files in `./policies`, deeply merging `ExtensionSettings` and
`URLAllowlist` while writing the final output to `merged-policy.json`:

```bash
chrome-policy-merge merge ./policies --merge-key ExtensionSettings --merge-key URLAllowlist --output-file ./policies/merged-policy.json --backup-dir ./policies/backup
```

Preview the same run without writing output or moving files:

```bash
chrome-policy-merge merge ./policies --dry-run --verbose
```

Restore the newest backup snapshot back into `./policies`:

```bash
chrome-policy-merge restore ./policies --backup-dir ./policies/backup
```

## CLI Usage

Top-level help:

```text
usage: chrome-policy-merge [-h] [--version] {merge,restore} ...
```

Merge command:

```text
usage: chrome-policy-merge merge [-h] [--merge-key KEY] [--output-file PATH]
                                 [--backup-dir PATH] [--dry-run] [--strict]
                                 [--verbose | --quiet]
                                 input_directory
```

Restore command:

```text
usage: chrome-policy-merge restore [-h] [--backup-dir PATH] [--snapshot NAME]
                                   [--output-file PATH] [--remove-output]
                                   [--dry-run] [--verbose | --quiet]
                                   input_directory
```

Key options:

- `input_directory`: directory scanned non-recursively for candidate JSON policy files.
- `--merge-key`: repeatable top-level policy name that should use deep merge behavior.
- `--output-file`: merged output path. Defaults to `merged-policy.json` inside the input directory. The output file cannot live inside the backup directory.
- `--backup-dir`: backup root for timestamped snapshots. Defaults to `backup` inside the input directory.
- `--dry-run`: validate, discover, and merge in memory without writing or moving files.
- `--strict`: fail on conflicting replacements for non-merge keys and on incompatible deep-merge types.
- `--verbose` / `--quiet`: raise or lower log verbosity.
- `--snapshot`: restore a specific snapshot directory name from the backup root. If omitted, the newest snapshot is used.
- `--remove-output`: remove the merged output file after a successful restore.

## Merge Semantics

Files are merged in natural filename order, so `policy2.json` is processed before
`policy10.json`.

Default behavior for keys not listed in `--merge-key`:

- Later files replace earlier values for the same top-level key.
- With `--strict`, conflicting replacements become errors instead of silent overrides.

Behavior for keys listed in `--merge-key`:

- `dict` + `dict`: recursively deep merged.
- `list` + `list`: ordered union. Existing items stay first; new unique items are appended.
- Scalar values at leaf nodes: later files replace earlier values.
- Incompatible container types: replaced by default, or rejected with `--strict`.

List uniqueness is based on JSON value equality, so duplicate strings, numbers, objects, or
lists are only emitted once in the final merged list.

## Backup Behavior

Each successful merge creates a new snapshot directory inside the backup root. Snapshots are
timestamped and never overwrite earlier backups. Every snapshot includes:

- the original source JSON files
- a `manifest.json` file with merge metadata

The tool validates all inputs before any source file is moved. If validation fails, the run
aborts without writing output or changing the input directory.

Restore copies files back into the input directory and refuses to overwrite existing policy
files. Select snapshots by directory name from the backup root, not by arbitrary filesystem
path.

## Library API

Chrome Policy Merge 4.0.0 also exposes a Python API:

```python
from pathlib import Path

from chrome_policy_merge import MergeConfig, merge_policy_directory

result = merge_policy_directory(
    MergeConfig(
        input_directory=Path("policies"),
        merge_keys=("ExtensionSettings", "URLAllowlist"),
    )
)

print(result.output_file)
print(result.processed_files)
```

Restore from Python:

```python
from pathlib import Path

from chrome_policy_merge import RestoreConfig, restore_backup_snapshot

result = restore_backup_snapshot(
    RestoreConfig(input_directory=Path("policies"))
)

print(result.snapshot_dir)
```
